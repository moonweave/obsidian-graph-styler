# 성단형 공간 시안 — 검토용, 제품 코드 아님

질문: 원반형 배치 대신, 3D 부피를 가진 노트 무리 사이에서 실제 깊이와 공간 탐색이 느껴지는가?

실행: 이 폴더에서 `python3 -m http.server 8766 --bind 127.0.0.1`, 브라우저로 `http://127.0.0.1:8766` 열기.

색: 잉크 배경 #070a0e, 연구 #a6c9da, 제품 #c2b5d4, 아이디어 #c6c2a7, 운영 #96bcb0, 기록 #b5bfd1. 시스템 산세리프를 쓰고, 설명과 조작은 화면 가장자리로 보낸다. 노드와 공간이 주인공이다.

단일 컨셉을 전체·측면·무리 사이의 세 카메라 시점으로 비교한다. 사용자의 하나씩 선별하는 방식에 따라 컨셉 변형 세 개를 한꺼번에 추가하지 않는다. 240개 샘플 노드만 사용하며 원본 Vault, 플러그인, 실제 데이터와 연결하지 않는다. 배경 별, 안개, 궤도 링, 비현실적인 빛줄기를 사용하지 않는다.

드래그 회전, 휠 확대, 노드 클릭 진입, 직접 연결 강조, 자동 회전, 공간 이동 재생, 시점 초기화. 상태는 메모리에만 남는다. URL은 시점만 기록한다. 동작 감소 설정이 켜져 있으면 자동 이동은 시작하지 않는다.

채택 여부는 사용자가 실제로 돌려본 뒤 결정한다. 이 시안은 플러그인 설치/릴리스에 포함하지 않는다.
